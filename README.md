# 🌐 Fundamentos de HTML 🚀

¡Bienvenido/a a este repositorio dedicado a aprender y repasar las bases de **HTML (HyperText Markup Language)**! Aquí encontrarás los conceptos esenciales para estructurar y dar contenido a cualquier página web desde cero. 💻✨

---

## 📂 Contenido del Repositorio

*   📁 `01-introduccion/` - ¿Qué es HTML y cómo funciona la Web? 🌍
*   📁 `02-estructura-basica/` - Anatomía de un documento HTML (`<html>`, `<head>`, `<body>`) 🏗️
*   📁 `03-textos-y-parrafos/` - Títulos, párrafos, negritas y cursivas 📝
*   📁 `04-enlaces-e-imagenes/` - Cómo conectar páginas e insertar contenido visual 🔗🖼️
*   📁 `05-listas-y-tablas/` - Listas ordenadas, desordenadas y organización en tablas 📊
*   📁 `06-formularios/` - Captura de datos de usuarios (inputs, botones, labels) 📋
*   📁 `07-proyecto-final/` - Una página web completa aplicando todo lo aprendido 🏆

---
